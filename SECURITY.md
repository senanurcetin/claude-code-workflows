# Security Policy

This repository holds Markdown skills, templates and one standard-library check script. Only the `main` branch is maintained, and no response-time SLA is promised.

If a skill or template could lead someone to leak credentials, run untrusted code or publish private data, report it privately through **Security → Report a vulnerability** on this repository instead of a public issue. Do not paste tokens, private transcripts or personal data into issues, PRs or Discussions.

Unclear or wrong advice that is not a security risk is a normal issue: use the "Skill gave wrong or unclear guidance" form.
